# 4-bit ALU using Verilog HDL

## Project Overview
Designed and implemented a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs basic arithmetic and logical operations including addition, subtraction, AND, and OR based on control signals. The design is verified using a testbench in Vivado behavioral simulation.

## Features
- 4-bit input ALU design
- Supports arithmetic operations: ADD, SUB
- Supports logical operations: AND, OR
- Control signal-based operation selection
- Verified using testbench simulation

## Tools Used
- Verilog HDL
- Xilinx Vivado

## Verification Method
- Behavioral simulation in Vivado
- Custom testbench used for functional verification
- Output waveform validated for all operation modes

## Project Files
- `alu.v` → Main ALU design module
- `testbench.v` → Testbench for simulation and verification

## Key Learning Outcomes
- RTL design using Verilog HDL
- ALU architecture design fundamentals
- Testbench creation and simulation flow in Vivado
- Digital logic design verification techniques
